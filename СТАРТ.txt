BASA Production

Как открыть
Распакуйте папку BASA-site целиком и откройте index.html в браузере. Английская версия — en.html. Сборка и установка пакетов для просмотра не требуются.

Как разместить на хостинге
Для обычного статического хостинга загрузите index.html, en.html, settings.js и папку assets в один каталог. Работает и в подпапке домена. Тексты находятся в двух HTML-файлах, стили — в assets/site.css, изображения — в assets/media. Шрифты встроены в assets/type.css, лицензии лежат в assets/fonts.

Контакты и работы
Telegram @basa69 и X @basaprod уже подключены. Карточка услуги открывает подробности, кнопка в ней переводит в переписку с черновиком сообщения. Посетитель отправляет его сам.
В settings.js вставьте адрес своего профиля Behance в behanceUrl. Пока поле пустое, «Работы» открывает проект на странице. «Вулкан Live» и пример превью помечены как концепты. Кадр рабочего места в разделе «Обо мне» — иллюстрация. Его можно заменить своей фотографией, обновив about.webp и about-sm.webp и описания изображений в обеих версиях.

Видео с RUTUBE
Вставьте ссылку на канал вида https://rutube.ru/channel/ЧИСЛОВОЙ_ID/ или сам числовой ID в rutubeChannel в settings.js. Адрес вида /u/имя/ включает переход на канал. Для автоматической ленты нужен числовой ID.
Пока канал и список роликов пусты, в видеоблоке есть ссылка для запроса видео в Telegram. Когда появляются видео, сайт показывает до восьми последних публичных роликов. Карусель пролистывается свайпом и кнопками, если карточки не помещаются. Плеер загружается после нажатия. Если просмотр внутри сайта ограничен владельцем видео, под плеером есть прямая ссылка на RUTUBE.

Рекомендуемый вариант для автоматического обновления
На хостинге с Node.js 20 или новее укажите канал в settings.js и запустите из каталога сайта:
    node tools/server.cjs
Локальный адрес по умолчанию — http://127.0.0.1:8080. Для хостинга укажите HOST и PORT согласно его настройкам. После изменения settings.js перезапустите процесс. Сервер проверяет канал по запросу при просмотре видеоблока, если предыдущему результату больше часа. При временной ошибке сохраняет предыдущий результат и повторяет попытку через пять минут при следующем обращении. Для сохранения снимка между перезапусками процессу нужна запись в assets/videos.js.

Если у вас статический хостинг
Сайт пробует получить ленту напрямую. Доступность запроса зависит от политики RUTUBE. Для регулярного обновления без этой зависимости запланируйте на хостинге или в процессе публикации ежечасную команду:
    node tools/server.cjs --sync
При успехе обновляется assets/videos.js. Если команда выполняется на другом компьютере или в CI, загрузите полученный файл на хостинг. Сохранённый результат работает и при открытии сайта с диска. При ошибке синхронизации старый файл сохраняется.

Если доступны только ссылки на два ролика
Можно сразу добавить их в список videos в settings.js и позже подключить канал. Для каждого укажите url и title. Поле titleEn необязательно. Пример структуры одной записи:
    { url: 'https://rutube.ru/video/ID_РОЛИКА/', title: 'Заголовок ролика', titleEn: 'English title' }
Если получена лента с канала, сайт использует её актуальные ролики. Переводы заголовков можно хранить в videos для соответствующих ссылок.

Аналитика
При просмотре страницы, открытии деталей и нажатии кнопок сайт создаёт локальные события в window.dataLayer. Внешний счётчик можно подключить через свой менеджер тегов. В текущей сборке события хранятся только в браузере на время просмотра страницы.
    basa_page_view         Просмотр языковой версии
    basa_service_open      Открытие услуги или формата YouTube, параметр item
    basa_case_open         Открытие концепта
    basa_telegram_click    Переход к диалогу, параметр placement
    basa_work_click        Переход к работе или в Behance, параметр destination
    basa_video_open        Открытие плеера, параметр video_id
    basa_x_click           Переход в X
    basa_language_change   Переключение языка, параметр to
Каждое событие содержит language. Реальные обращения и заказы учитывайте по входящим сообщениям. Несколько кликов одного посетителя могут относиться к одному обращению.
